# Anomalías en Cañerías de Edificios

Edificios tienen activos críticos de los cuales necesitan mantención y de alguna forma, prevenir fallos. Uno de los activos críticos presentes en edificios son las cañerías.

## Descripción general

Este trabajo se enfoca en el monitoreo y análisis de activos críticos en infraestructuras, como las cañerías, con el fin de realizar mantenciones preventivas y evitar fallos inesperados. A través de técnicas de análisis de datos y aprendizaje no supervisado, se buscan patrones anómalos que podrían indicar problemas en el sistema.
